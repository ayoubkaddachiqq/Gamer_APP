# TeamHub

TeamHub is a Java (Maven) application with an auxiliary Python face_service for face recognition.

Build: use `mvnw` on Windows: `mvnw.cmd package` or `mvn package` if Maven is installed.

The face_service has Python dependencies in `face_service/requirements.txt` and can be run with `python face_service\main.py`.
